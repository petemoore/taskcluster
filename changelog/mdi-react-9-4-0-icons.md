Upgraded the `mdi-react` icon library in the UI from 6.7.0 to 9.4.0. Six icon
modules removed or renamed in the new Material Design Icons set were swapped for
their current equivalents: `FilePdfIcon` → `FilePdfBoxIcon`, `GithubBoxIcon` and
`GithubCircleIcon` → `GithubIcon`, `WarningIcon` → `AlertIcon`, and the removed
`WorkerIcon`/`MixcloudIcon` → `AccountHardHatIcon`. These are name-only changes;
the icon component API is unchanged.
